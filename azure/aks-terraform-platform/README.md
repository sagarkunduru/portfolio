# Azure / AKS Terraform Platform

## Objective
Show the Azure side of the same production engineering model: repeatable infrastructure, Kubernetes delivery, identity/security controls and operations.

## Components
- Resource groups and virtual networking
- AKS
- Azure Container Registry
- Azure Key Vault
- Azure Monitor
- Azure RBAC / Entra ID integration concepts
- Terraform
- Azure DevOps-style gated delivery
- Azure Policy governance concepts

## Regulated-environment mindset
Infrastructure changes should be repeatable, reviewable and auditable. Policy, RBAC, encryption, centralized logging and documented operating procedures are treated as platform requirements rather than optional additions.

This is a reference lab and does not reproduce a government or customer environment.
